The guarantee is one durable admission, not exactly-once provider execution: `SessionV2.prompt` may request an execution wake for each call. Known v2 4xx rejection preserves the draft; ambiguous transport outcomes are marked unknown and preserve it. Drafts clear only after a validated accepted admission for the current attempt, so an older unknown result cannot finish a newer retry.
